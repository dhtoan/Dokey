글자가 씹히지 않는 맥 한글 입력기

Dokey는 macOS용 무료 입력기입니다. 두벌식으로 입력하면 조합 중인 글자에 밑줄 없이 바로 완성된 글자가 나타납니다. Chrome, Edge, Claude, ChatGPT, Notion 같은 웹·Electron 앱에서도 한글이 씹히거나 자모가 분리되지 않도록 만들었습니다.

왜 Dokey인가요?

웹과 Electron 앱에서 자주 겪는 한글 입력 문제를 처음부터 다시 설계해 해결했습니다.

⚡

글자 씹힘 방지

키를 누를 때마다 음절 전체를 다시 조합하고, 바뀐 글자만 입력 위치에서 바로 고칩니다.

✍️

밑줄 없는 즉시 입력

조합 중 밑줄(마크드 텍스트)을 쓰지 않아, Enter를 눌러도 마지막 글자가 두 번 입력되지 않도록 설계했습니다.

⌨️

표준 두벌식

키 위치로 읽기 때문에 키보드 배열과 관계없이 정확합니다. Shift + q w e r t로 ㅃ ㅉ ㄸ ㄲ ㅆ.

⌫

자모 단위 지우기

Backspace는 한 자모씩 지웁니다: 한 → 하 → ㅎ.

🇻🇳

베트남어도 함께

Telex·VNI 베트남어 입력과 맞춤법 검사를 같은 앱에서. 메뉴 막대에서 바로 전환하세요.

🔒

개인정보 보호

모든 처리는 Mac 안에서만 이루어집니다. 네트워크 연결도, 키 입력 기록도 없습니다.

자주 묻는 질문

맥에서 Chrome이나 Claude를 쓸 때 한글이 씹히는 이유는 무엇인가요?

Chrome과 Electron 앱은 키 입력을 별도 프로세스에서 처리하기 때문에, 입력기가 보낸 수정 키와 새 글자가 어긋나거나 사라질 수 있습니다. Dokey는 수정할 글자만 입력 위치에서 바로 선택해 덮어쓰고, 사용자가 누르고 있는 키의 코드를 쓰지 않아 글자 씹힘을 줄였습니다.

Enter를 누르면 마지막 글자가 중복되거나 자모가 분리돼요. Dokey는 어떤가요?

이 문제는 보통 조합 중인 글자(밑줄 표시)를 앱이 제대로 확정하지 못해 생깁니다. Dokey는 조합 중 밑줄을 쓰지 않고 항상 완성된 글자를 바로 입력하므로, 이런 유형의 문제가 생기지 않도록 설계되었습니다.

Dokey는 무료인가요?

네. 개인 사용자는 무료로 사용할 수 있고, 광고나 유료 버전이 없습니다.

Dokey는 안전한가요? 키 입력을 기록하나요?

Dokey는 Mac 안에서만 동작하며 네트워크에 연결하지 않고 키 입력을 저장하지도 않습니다. macOS에서 키를 받아 고치려면 모든 입력기와 마찬가지로 손쉬운 사용 권한이 필요합니다.

어떤 자판을 지원하나요?

한국어는 표준 두벌식을 지원합니다. 세벌식은 아직 지원하지 않습니다. 베트남어는 Telex와 VNI를 지원합니다.

한글과 영문은 어떻게 전환하나요?

Control + Shift(⌃⇧)를 눌렀다 떼면 한글과 영문이 바뀝니다. 다른 단축키로 바꿀 수 있고, 앱마다 마지막 모드를 기억합니다.

macOS 기본 한글 입력기와 함께 써도 되나요?

Dokey를 쓸 때는 macOS 입력 소스를 ABC(또는 U.S.)로 두세요. 기본 2벌식 입력 소스가 켜져 있으면 두 입력기가 동시에 조합하게 됩니다.
